# Mitmachen

Danke für dein Interesse!

## Issues

Fehler, unklare Erklärungen oder Ideen bitte als Issue melden. Nenne die betroffene ID (z. B. `t03-c012`) und, wenn möglich, einen Verbesserungsvorschlag.

## Pull Requests

1. Fork erstellen, Branch anlegen.
2. Änderungen klein und thematisch fokussiert halten.
3. `uv run pytest` ausführen; die Tests müssen bestehen.
4. Commit-Nachrichten auf Englisch im Conventional-Commits-Stil (`feat:`, `fix:`, `docs:`, `chore:`).

## Eigene Worte

Beiträge müssen in eigenen Worten verfasst sein. Keine Texte, Aufgaben, Beispiele oder Abbildungen aus Skripten, Folien, Büchern oder Klausuren übernehmen. Allgemeine Definitionen und Lehrbuch-Szenarien sind erlaubt, wenn sie selbst formuliert sind.

## Quellenpflicht

Jede fachliche Aussage, die nicht Allgemeinwissen ist, braucht eine Quelle. Quellen werden in `sources.yml` geführt und im Inhalt per ID referenziert.

## Lizenz

Mit deinem Beitrag stimmst du zu, dass Inhalte unter CC BY-SA 4.0 und Code unter MIT veröffentlicht werden.
